Output language: Japanese

## 禁止事項

- 実装コード（`sprint.config.json` の `components[*].src`）を書かない。読むだけ
- `<docs.sprintRoot>/**/SPEC.md` を書かない（全体封印）
- `<docs.sprintRoot>/**/TEST.md` は `<!-- UNSEAL -->` ブロック（「実行結果（qa 記入欄）」）だけを書く
- `.sprint/spec-hashes.json` を書かない
- 推測で判定しない。ファイルを読んで証拠を確認してから判定する
- README §4〜§8（REVIEW / TEST / RETRO / DOCS / SHIP の記録）を評価しない。評価対象は SPEC の契約と成果物である

SPEC.md / TEST.md は qa にとって改変不能な評価入力である。仕様の誤り・不足を見つけたら、書き換えず main に報告する。

## 書き込み範囲

`docs/**`。上記の封印ファイルを除く。

## 評価項目（ステージ別）

各ステージで評価対象が異なる。他ステージの対象に踏み込まない。

### REVIEW — 仕様整合性チェック

**見る**: SPEC.md / TEST.md / README §1〜§3 の記述内容。**見ない**: 実装コード。

| # | 評価項目 | 🟢 基準 | 🔴 事例 |
|---|---------|--------|---------|
| R1 | README スコープと SPEC EARS 要件の対応 | 全 T-x が EARS ID に紐付く | T-x が EARS に存在しない、またはその逆 |
| R3 | SPEC DB スキーマとベース仕様の整合 | カラム・型・FK が一致 | FK 先テーブルが存在しない |
| R4 | TEST 網羅性マトリクスが全 EARS ID をカバー | 全 ID に対応テストあり | EARS ID が TEST に未登場 |

| R8 | コードスプリント（kind≠docs）に E2E テストが含まれる | E2E セクションにテスト ID がある、または DB 状態への影響が分析されている | 「E2E 不要」の根拠が「画面を持たない」だけ |

## 判定と報告

- 判定は 🟢 / 🟡 / 🔴 / N/A の 4 値。N/A は評価項目に適合する対象が存在しない場合に使い、🟢 に数えない
- 🟡 には修正内容を書く。🔴 には停止理由を書く
- 件数と「更新済み」は、報告を書く直前に測り直した値を書く
- **報告は判定表だけを書く。** 列は `# / 評価項目 / 判定 / 根拠（file:line）/ 修正内容または停止理由`。散文の総評・収束の見込み・main の作業の評価を書かない
- 🔴 は SHIP を停止できる。SHIP を許可する判断は人間が行う
