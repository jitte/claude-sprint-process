# [層の名前]（上位仕様）

> 雛形の使い方: ファイルの先頭に frontmatter を置く。`PFX` を層の prefix（英大文字 2〜6 字。コーパスで一意）に、`n` を 1 からの連番に置き換える。`[ ]` の中を埋め、この引用ブロックは消す。
> アンカー行は `bash harness/tools/clause-anchors.sh` が付けるので手で書かなくてよい。
>
> ```yaml
> ---
> xref-prefix: PFX
> layer: [任意。common / core / supporting / generic / operation / frontend / design のいずれか]
> ---
> ```

> **[この層が何をするかを 1〜2 文で書く。]**
>
> 下位の [N] 本はこの特化である。ここに書かれた規範を再記述せず `[ID](<相対パス>#ID)` で参照し、固有の差分だけを書く。

## 3. 下位仕様が書く差分

<a id="PFX-n"></a>
### [PFX-n] 下位が書き足すこと

| 書く | 書かない |
|---|---|
| [そのモジュール固有の責務と境界] | 上位に書かれた規範の再記述（`[ID](<相対パス>#ID)` で参照する） |
| [固有の規範] | [全モジュールに共通する規範] |
| [固有の API または画面の振る舞い] | [共通の形（ページネーション・エラーの形）] |
| [固有のテスト観点] | [共通パターンのテスト観点] |

- 上位の規範に条件を足すときは、上位を参照したうえで追加条件だけを書く
- 上位の規範と食い違うときは、下位に書かず上位を直す
